
# Multimodal Image Generation Studio

## Project Overview

An AI-powered application that converts text descriptions
into digital artwork using an image generation API.

## Features

- Text-to-image generation
- Multiple image styles
- Square, landscape and portrait sizes
- Generate one or two images
- Image preview
- Download generated images
- Save generated images locally

## Technologies Used

- Python
- Streamlit
- Requests
- AI Horde Image Generation API

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## API

AI Horde Image Generation API:
https://aihorde.net/api/v2
